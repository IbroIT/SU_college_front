# 🔍 Как проверить что SEO работает

- SEO компоненты: ✅
- Базовые мета-теги: ✅

## 🚀 Шаги для проверки SEO

### 1. Локальное тестирование

#### Запустите сервер:
```bash
npm run dev
```

#### Откройте браузер:
```
http://localhost:5173
```

#### Используйте встроенный SEO Debugger:
1. В правом верхнем углу найдите кнопку **"🔍 SEO Debug"**
2. Кликните по ней для открытия панели отладки
3. Проверьте все мета-теги в реальном времени

### 2. Проверьте статические файлы

#### robots.txt:
```
http://localhost:5173/robots.txt
```

#### sitemap.xml:
```
http://localhost:5173/sitemap.xml
```

### 3. Тестируйте многоязычность

1. **Переключите языки** в навигации:
   - Русский (по умолчанию)
   - English 
   - Кыргызча

2. **Проверьте что обновляется**:
   - Заголовок страницы (title)
   - Описание (description)  
   - Ключевые слова (keywords)
   - Open Graph теги
   - Hreflang ссылки

### 4. Проверьте разные страницы

Протестируйте SEO на всех основных страницах:
- **Главная**: `/`
- **О колледже**: `/about`
- **Новости**: `/news`
- **Программы**: `/programs/computer-science`
- **Абитуриенту**: `/admissions/specialties`
- **Контакты**: `/contacts`
- **FAQ**: `/faq`
- **Вакансии**: `/vacancies`

## 🔧 Chrome DevTools для SEO

### Проверка мета-тегов:
1. Откройте **DevTools** (F12)
2. Перейдите на вкладку **Elements**
3. Найдите `<head>` секцию
4. Проверьте все мета-теги

### Проверка структурированных данных:
1. В **DevTools** найдите скрипты с `type="application/ld+json"`
2. Скопируйте JSON и проверьте в [Schema.org validator](https://validator.schema.org/)

### Проверка производительности:
1. Вкладка **Lighthouse** в DevTools
2. Запустите аудит для **SEO** категории
3. Получите оценку и рекомендации

## 📱 Мобильное тестирование

### В Chrome DevTools:
1. Нажмите **Ctrl+Shift+M** (Toggle device toolbar)
2. Выберите различные устройства
3. Проверьте отображение на мобильных

### Проверьте:
- Viewport мета-тег работает
- Контент адаптируется
- Кнопки легко нажимаются
- Текст читабелен

## 🌍 Мультиязычное тестирование

### Автоматическая проверка hreflang:
```bash
# Проверьте что каждая страница имеет правильные hreflang теги
curl -s http://localhost:5173/ | grep "hreflang"
curl -s http://localhost:5173/about | grep "hreflang"
```

### Ручная проверка:
1. Откройте страницу на русском
2. Переключитесь на английский
3. Убедитесь что:
   - URL изменился на `/en/`
   - Мета-теги обновились
   - Контент переведен

## 📊 Что проверять в SEO Debugger

### ✅ Хорошие показатели:
- **Title**: 30-60 символов
- **Description**: 120-160 символов  
- **Keywords**: 5-10 релевантных слов
- **OG теги**: все заполнены
- **Structured Data**: присутствует
- **Hreflang**: все языки указаны

### ⚠️ На что обращать внимание:
- Дублирующиеся мета-теги
- Слишком длинные/короткие заголовки
- Отсутствующие OG изображения
- Неправильные canonical URL

## 🚨 Частые проблемы и решения

### Проблема: Мета-теги не обновляются при смене языка
**Решение**: Проверьте что `react-helmet-async` правильно обернут в `HelmetProvider`

### Проблема: Структурированные данные не отображаются
**Решение**: Проверьте JSON синтаксис в компоненте `StructuredData`

### Проблема: Hreflang теги неправильные
**Решение**: Убедитесь что `LanguageManager.generateHreflangTags()` вызывается
